# Colab-specific install list.
#
# torch and torchvision are listed together deliberately. If only one of
# them is pinned (or one is left out entirely), pip can silently upgrade
# torch as a transitive dependency of diffusers/transformers/accelerate
# while leaving the previously-installed torchvision behind — the two
# become ABI-incompatible and you get errors like
# "RuntimeError: operator torchvision::nms does not exist".
# Listing both here forces pip to resolve them together in one solve:
# torchvision's own metadata pins the exact torch version it needs, so
# pip reconciles both correctly instead of upgrading just one.

torchvision>=0.16.0
diffusers>=0.27.0
transformers>=4.38.0
accelerate>=0.27.0
