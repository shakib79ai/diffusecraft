# Colab-specific install list.
#
# torch/torchvision are deliberately NOT listed here. Colab preinstalls
# them already paired with a much larger CUDA-toolkit-versioned stack
# (RAPIDS cuml/cudf, xformers, etc.), and letting pip re-resolve either one
# -- even just to satisfy a loose diffusers/transformers floor -- can pull
# in a torch build linked against a different CUDA major version and break
# that entire preinstalled stack.
#
# The notebook instead generates constraints.txt, pinning torch/torchvision
# to whatever Colab already has, and passes it via `pip install -c
# constraints.txt`. A constraints file caps versions without adding
# packages: if any dependency here needs a newer torch than what's pinned,
# pip will fail loudly with a clear resolution error instead of silently
# upgrading torch and breaking the rest of the environment.

diffusers>=0.27.0
transformers>=4.38.0
accelerate>=0.27.0
gradio>=4.19.0
Pillow>=10.0.0
